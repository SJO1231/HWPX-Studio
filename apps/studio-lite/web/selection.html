내 PC에서 처리
템플릿과 데이터를 올려 자리별 블록을 확인하세요.

블록 선택

조건에 따른 기본값을 확인하고, 이번 건에 사용할 블록을 고릅니다.

JSON 객체 하나 또는 객체 배열을 지원합니다.

참조하는 파일

템플릿이 참조하는 원본·원형·조각을 함께 선택하세요. 올린 원본은 덮어쓰지 않습니다.

이번 건 선택 보관

템플릿과 데이터를 먼저 올린 뒤 이번 건을 불러오세요. 직접 선택과 확정은 해당 데이터 행에만 적용됩니다. 다른 데이터 파일에는 이전 선택을 자동 적용하지 않습니다.

현재 지원 범위

새 템플릿 형식의 한 단계 블록 선택을 지원합니다. 중첩 블록과 기존 프로젝트 자동 이관은 후속 작업입니다. 파일은 현재 화면 메모리에서 다루며, 재사용할 선택은 이번 건 JSON으로 내려받으세요.

자리별 블록 선택

직접 고른 선택은 조건이 달라져도 유지됩니다.

템플릿 확인 전

파일을 올린 뒤 연결·기본 블록 확인을 누르세요.

데이터 연결 확인

원본 값을 수정하지 않고 템플릿의 연결로 읽습니다.

문서 생성

자리마다 선택 상태를 먼저 확인하세요.
