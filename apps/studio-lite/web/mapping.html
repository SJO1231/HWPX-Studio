데이터 연결

템플릿의 항목을 원본 데이터에 연결하고, 변경한 연결은 새 판으로 보관합니다.

JSON은 원래 구조를 그대로 읽습니다.

여러 시트가 있으면 두 번째 이후 데이터 시트를 선택합니다.

    참조하는 파일

    템플릿이 참조하는 원형과 조각을 함께 올리세요. 원본과 공용 블록을 바꾸지 않습니다.

    새 데이터에 재사용

    연결을 새 판으로 보관하고 템플릿 JSON을 내려받으세요. 내려받은 템플릿을 다시 올려 다른 데이터와 연결할 수 있습니다.

    항목별 연결표

    템플릿 확인 전

    원본 열 이름은 공백과 점을 포함해 그대로 씁니다. JSON 안쪽 값을 읽을 때만 중첩 경로를 선택하세요.

    위치는 템플릿에 지정된 정보입니다. 실제 원본 대상은 생성 단계에서 확인합니다. 문단 경로와 글 위치는 0부터 셉니다.

    템플릿 항목데이터 연결현재 값 / 상태적용 위치
    템플릿과 데이터를 올린 뒤 연결표 확인을 누르세요.

    파일은 현재 화면에서 다룹니다. 업로드한 템플릿 파일은 덮어쓰지 않습니다.

    현재 데이터의 원본 열

    열 이름을 클릭해 자동 변경하지 않습니다. 연결표에서 직접 확인·수정하세요.

    변경 범위

    연결을 수정하면 현재 값은 다시 확인해야 합니다.

    이 화면은 템플릿의 데이터 연결만 바꿉니다. 원본 데이터 값·공용 블록·이번 건 수정은 바꾸지 않습니다.

    SQLite 자동 연결, 이번 건 값 정정, 문서 생성은 이 화면의 범위가 아닙니다. 새 연결의 파일 저장과 재사용부터 확인하세요.
