# 진행 방향

- 이 문서가 소유하는 주제: 단계 순서와 범위. 상태는 [작업 기록](task-record.md)에 둔다.
- 순서 원칙: 화면을 크게 만들기 전에 "수정 → 재패키징 → 정상 문서"를 먼저 입증한다.

## 1차 — 엔진 핵심 (CLI)

| 과업 | 내용 | 수용 기준 |
| --- | --- | --- |
| S1 | 패키지(ZIP 읽기·쓰기), XML 토크나이저·트리, 문서 모델(자원·본문·주소·논리 텍스트), 모델 JSON 내보내기 | [엔진 명세](engine-spec.md) 6절 |
| S2 | 조각 추출·가져오기(문단·표·그림, 자원 의존 닫힘, 지문 비교, ID 재매핑, 삽입) | [검증 기준](validation.md) 5절, E9 |
| S3 | 채움(누름틀·단어·줄·셀), 조건 삭제·주입, 서식 상속 텍스트 삽입, 검사기와 저장 게이트, CLI | E1~E13 |
| S2b | 서식 변경: 복제 후 일부 변경, 같은 모양 재사용, 구간 적용 시 run 쪼개기, 드문 서식 | [엔진 명세](engine-spec.md) 7.7 |
| 스트레스 | 무관한 실제 문서 사이의 길고 복잡한 조각 삽입(통째·쪼개기·연쇄·셀 안), 서식 변경 조합, 실패 원인별 수정과 재실행 | [엔진 명세](engine-spec.md) 7.8 |
| S3c | 오류 보정: id 재발급, 개수 속성, 낡은 조판 캐시, 금지 문자, 책갈피 이름. 없는 참조 대체와 패키지 재배열은 선택 | [엔진 명세](engine-spec.md) 8.35 |
| S4 | md·txt 어댑터(최소): `{{}}` 채움, 줄 앵커, 조건 삭제·블록 주입, 텍스트 삽입. 규칙·데이터 계층은 hwpx와 공유 | [엔진 명세](engine-spec.md) 9절 |
| 검증 | 독립 검증, 오라클 교차, 실문서 표본, 식별자 대조 | E14, 라이선스 점검 |

순서: S1 → (S2 ‖ S3a 검사기) → (S2b 서식 변경 ‖ 스트레스 시험 ‖ S3c 오류 보정 ‖ S3b 채움·규칙·CLI) → S4 → 검증. 검출한 결함은 그때그때 재현 테스트를 붙여 고치고 스트레스 시험을 다시 돌린다.

형식 우선순위: HWPX를 먼저 완성한다. md·txt는 같은 규칙·데이터 계층을 쓰는 어댑터로 붙인다.

## 2차 — 화면과 추천

- rhwp 뷰어 통합: 렌더, 좌표↔앵커 변환.
- rhwp 편집창 통합: round-trip 게이트, 호스트 소유, 편집 결과 재파싱.
- 데스크톱 셸.
- 프로젝트 저장 형식 확정, 조각·데이터 묶음 라이브러리(DB).
- Jev-assist 0단계: 후보 자리, 데이터 키 매칭, 앵커 보조.
- 자동 템플릿 초안(문서 하나의 패턴 분석 → 누름틀·`{{}}`·JSON 초안 → 사용자 확정).
- 표 행 반복.
- 규칙 선택 화면(조건을 고르면 내부 JSON이 만들어진다), 규칙 충돌 검사, 미리보기.

## 3차 — 확장

- Jev-assist: 서식 패턴 추정, 조건 규칙 추천, 조각 추천, 템플릿 전이.
- 자동 템플릿 초안(같은 서식의 문서 여러 개를 대조해 고정 글과 가변 자리, 조건 블록·반복 후보를 찾고 문서별 데이터 사례를 뽑는다. 자기 검증 후 사용자 확정).
- 매핑 화면: 드래그, `{{` 자동완성.
- md/txt에서 새 문서를 만드는 생성 모드.
- 돌발상황 매트릭스의 자동 시험.
- 한컴 COM 보조(문서 전체 삽입, PDF 대조).
- 일괄 생성, 규칙 시험 표.
